servidor de terraria para arduino

por agora o projeto está em fase inicial, implementando os pacotes e sem nenhuma otimização

algumas funcionalidades podem ser implementadas mesmo que em uma futura versão finalizada tenham que ser removidas (ex.: suporte para customização do jogador, economizaria recursos se não tivessemos que alocar esses dados)

não faço a menor ideia se no final das contas realmente conseguirá rodar em um arduino XD

projeto inspirado no [bareiron](https://github.com/p2r3/bareiron)
